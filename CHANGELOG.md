# Changelog

## 2.0.3

- Added an optional EU VAT number field to WooCommerce checkout (classic + block API registration).
- Added VIES validation with transient caching and resilient fallback when VIES is unreachable.
- Added automatic reverse-charge tax exemption for valid intra-EU B2B checkout flows.
- Added VAT/VIES order metadata persistence, admin badges, re-check action, and email/invoice phrasing.
